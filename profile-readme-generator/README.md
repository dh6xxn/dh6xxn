# GitHub Profile README Generator

A client-side generator for polished GitHub Profile `README.md` files.

## MVP

- Build a profile from structured sections
- Toggle sections on/off
- Generate Markdown instantly
- Preview the resulting profile
- Download `README.md`
- No account or server required

## Template

The first template is based on the structure of [dh6xxn/dh6xxn](https://github.com/dh6xxn/dh6xxn), adapted into reusable fields rather than hard-coded personal content.

## Planned sections

- Hero
- About Me
- What I'm Exploring
- Tech Stack
- GitHub Statistics
- Contribution Activity
- Contribution Snake
- Open Source
- GitHub Trophies
- What I'm Building
- Current Focus
- Learning Journey
- Social Links

## Development

The generator is intended to be a static GitHub Pages site. All profile data entered into the form is processed in the browser.
